# Twitch-Enotik-Unloker
Twitch Enotik Unloker - расширение для браузера, которое разблокирует качество 1080p/1440p/2K на Twitch без авторизации и подписки. Открытый исходный код, установка через GitHub Release, поддержка Chrome, Edge и Firefox.

## Возможности
- Разблокирует качество 1080p/1440p/2K на Twitch

## Установка

1. Скачайте архив из раздела [Releases](../../releases).
2. Распакуйте архив.
3. Откройте страницу расширений браузера.
4. Включите режим разработчика.
5. Нажмите «Загрузить распакованное» и выберите папку расширения.

Подробная инструкция: [INSTALLATION.md](https://github.com/darkicestormteam/Twitch-Enotik-Unloker/blob/main/Twitch%20Enotik%20Unloker/INSTALLATION.md)

## Быстрый переход к настройкам расширений

Чтобы не искать нужную страницу вручную, скопируйте и вставьте ссылку в адресную строку браузера:

- **Google Chrome / Brave / Opera:** `chrome://extensions`
- **Microsoft Edge:** `edge://extensions`
- **Firefox:** `about:debugging#/runtime/this-firefox`

## Безопасность и приватность
 Расширение не собирает персональные данные пользователей для аналитики, рекламы или трекинга.
- Сетевые запросы выполняются только к доменам Twitch.
- Для работы расширения используются технически необходимые разрешения: `cookies`, `storage`, `alarms`, `declarativeNetRequest` и доступ к доменам Twitch.
- Разрешения применяются исключительно для корректной работы функций расширения на страницах Twitch и не используются для отслеживания пользователя.
- Расширение не требует создания аккаунта, авторизации или подписки для разблокировки качества видео.
