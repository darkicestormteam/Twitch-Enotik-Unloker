# Release Notes

## v1.0.0 — первая публичная версия

### Что нового
- Первая публичная версия расширения.
- Добавлена базовая функциональность.
- Подготовлена инструкция по установке.

### Установка
1. Скачайте архив из GitHub Release.
2. Распакуйте архив.
3. Откройте страницу расширений:
   - Chrome / Brave / Opera: `chrome://extensions`
   - Edge: `edge://extensions`
   - Firefox: `about:debugging#/runtime/this-firefox`
4. Включите режим разработчика.
5. Нажмите «Загрузить распакованное» и выберите папку расширения.

Подробная инструкция: INSTALLATION.md

### Известные ограничения
- Автоматическая установка без подтверждения пользователя не поддерживается браузерами.
- В Firefox временная установка сбрасывается после перезапуска браузера.
