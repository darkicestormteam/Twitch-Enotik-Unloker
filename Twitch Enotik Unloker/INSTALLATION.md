# Установка расширения

## Быстрый переход к странице расширений

Скопируйте и вставьте ссылку в адресную строку браузера:

- **Google Chrome / Brave / Opera:** `chrome://extensions`
- **Microsoft Edge:** `edge://extensions`
- **Firefox:** `about:debugging#/runtime/this-firefox`

## Chrome / Edge / Brave / Opera
1. Скачайте архив расширения из GitHub Release.
2. Распакуйте архив в отдельную папку.
3. Откройте страницу расширений по ссылке выше.
4. Включите **Режим разработчика**.
5. Нажмите **Загрузить распакованное**.
6. Выберите папку, где лежит `manifest.json`.

## Firefox
1. Скачайте архив расширения.
2. Распакуйте архив.
3. Откройте `about:debugging#/runtime/this-firefox`.
4. Нажмите **Загрузить временное дополнение**.
5. Выберите файл `manifest.json`.

> В Firefox временные дополнения удаляются после перезапуска браузера. Для постоянной установки лучше использовать Firefox Add-ons или подписанный `.xpi`.

## Если расширение не устанавливается
- Проверьте, что выбрана папка с `manifest.json`.
- Убедитесь, что архив полностью распакован.
- Обновите браузер до актуальной версии.
- Проверьте, что в папке нет повреждённых файлов.

## Автоустановка
Автоматическая «тихая» установка расширения в обычных Chrome/Edge/Firefox не поддерживается из соображений безопасности. Пользователь должен подтвердить установку вручную.
